# cnc-erp

Очередь заданий для фрезерного станка со стойкой Syntec (Windows CE): программы `.cnc` загружаются в веб, агент на соседнем Windows-ПК кладёт их в память стойки по Remote API, выбирает основной и сообщает состояние станка и готовые детали. «Старт» нажимает оператор. На стойку ничего не ставится, в интернет она не выходит.

Ноутбук у станка — сразу и сервер, и шлюз. Отдельный компьютер не нужен.

Подробности: [docs/ВНЕДРЕНИЕ.md](docs/ВНЕДРЕНИЕ.md) (внедрение в цех), [docs/API.md](docs/API.md) (HTTP), [docs/HANDOFF.md](docs/HANDOFF.md) (решения и стенд).

## Завтра: от пустого ноутбука до проверки на станке

Что есть: станок, кабель Ethernet, ноутбук Windows 11 без программ, флешка.

Интернет у станка не нужен и не появится. Всё, что скачивается, ставится **сегодня вечером дома**. Завтра ноутбук работает только с кабелем до стойки.

Библиотеки Syntec в git не лежат. Папка для флешки уже собрана на компьютере, где делался проект:

`cnc-erp\agent\usb\CncAgent`

Скопировать её на флешку целиком. На ноутбуке заново её не собрать.

### Сегодня вечером, ноутбук в интернете

1. Поставить [Docker Desktop](https://www.docker.com/products/docker-desktop/) (движок WSL2, дождаться «running»; если попросит — включить виртуализацию и перезагрузиться) и [Node.js 20 LTS](https://nodejs.org/). Git ставится вместе с GitHub Desktop или с [git-scm.com](https://git-scm.com/).
2. Склонировать проект и поставить зависимости:

   ```bat
   git clone https://github.com/whanarchyven/chpu-driver.git
   cd chpu-driver
   npm ci
   ```

3. Один раз запустить сервер, чтобы скачались образы Docker. Адрес задать сразу таким, каким он будет у станка, иначе веб соберётся на домашний IP:

   ```bat
   set SERVER_IP=192.168.50.1
   Запустить-сервер.cmd
   ```

   Дождаться строк «Веб» и «Ключ агента». Окно закрыть. Остановка, если мешает: `docker compose -f server\docker-compose.yml down`.
4. Флешку с папкой `CncAgent` положить в сумку.

### Завтра у станка

Кабель — обычный патч-корд, переходник не нужен. Один конец в Ethernet ноутбука, другой в Ethernet стойки. Раздачу интернета (ICS) не включать. Wi-Fi ноутбука не трогать и шлюз на кабеле не задавать.

**1. Стойка**, станок остановлен.

- Сеть: IP `192.168.50.20`, маска `255.255.255.0`, шлюз пустой.
- «Обслуживание → Сеть → Core server» (может называться Remote / Core Server): включить, поставить запуск при включении, нажать «Запустить». Если пункт просит пароль обслуживания — он нужен здесь.
- Перезагрузить стойку и убедиться, что Core server поднялся сам.

**2. Ноутбук.** Параметры → Сеть → Ethernet → IP вручную:

| | |
|---|---|
| IP | 192.168.50.1 |
| Маска | 255.255.255.0 |
| Шлюз | пусто |
| DNS | пусто |

Проверка в командной строке: `ping 192.168.50.20`. Ответ есть — кабель и адреса верные.

**3. Сервер.** В папке проекта:

```bat
set SERVER_IP=192.168.50.1
Запустить-сервер.cmd
```

Если вчера `server\.env` создался с другим адресом, удалить `server\.env` и запустить снова. Открыть `http://192.168.50.1:5174`. Ключ агента — в окне скрипта (пока не меняли, это `cnc-stand-dev`).

**4. Агент с флешки.** `Установить.cmd`, согласиться на права администратора. Windows 11 уже содержит .NET 4.8, Visual C++ 2005 установщик поставит сам. Ответы:

| Вопрос | Ответ |
|---|---|
| IP сервера | 192.168.50.1 |
| IP стойки | 192.168.50.20 |
| Ключ агента | из окна сервера |
| Имя станка | velber-1 |

В конце установщик сам печатает, что видит на стойке.

**5. Проверка без резки**, с флешки.

- `Проверить-стойку.cmd` — «Связь есть: Syntec … ПО 10.118…, библиотека syntec-10.118», режим, состояние, программа, счётчик.
- `Проверить-передачу.cmd` — «ПЕРЕДАН через Remote API. В списке программ стойки: есть». Файл `ERP-TEST.CNC` движений не содержит.

**6. Проверка очереди.** В вебе «Программы» загрузить `ERP-TEST.CNC` с флешки, на «Очереди» поставить задачу на 1 деталь, станок `velber-1`. Через несколько секунд задача «загружена», на экране стойки основная программа `ERP-TEST.CNC`.

Дальше с оператором, без заготовки или с поднятым Z:

| Действие | В вебе |
|---|---|
| «Старт» | «в работе», растёт номер строки |
| «Сброс» посередине (на настоящей программе) | снова «загружена», деталь не засчитана |
| «Старт» и дождаться M30 | деталь засчитана, задача «выполнена» |

`ERP-TEST.CNC` кончается сразу, поэтому на нём виден сам факт: старт принят, деталь засчитана. После этого то же самое на короткой рабочей программе с поднятым Z.

### Если что-то не так

| Что видно | Что делать |
|---|---|
| ping не идёт | кабель, адрес стойки, шлюз на ноутбуке должен быть пустым |
| «стойка не отвечает», порт 5566 закрыт | Core server не включён или не стартовал после перезагрузки |
| «SocketError (-16)» | на флешке старая сборка без папки `agent\syntec-10.118`; взять папку `usb\CncAgent` заново |
| «стойка не приняла файл» с другим кодом | освободить память программ; если не помогает ни один файл — запасная папка, [docs/ВНЕДРЕНИЕ.md](docs/ВНЕДРЕНИЕ.md) |
| пункт Core server не нашли | сфотографировать меню «Обслуживание → Сеть» и остановиться: без него состояние станка не прочитать, файлы можно класть только в сетевую папку |
| веб не открывается | Docker Desktop запущен, в `.env` адрес `192.168.50.1` |

Журнал агента: `C:\Program Files (x86)\CncAgent\cnc-agent.log`.

## Состав

- `Запустить-сервер.cmd` — сервер одной командой (Docker). Порты 3220, 3221, 5174, 6792.
- `agent/CncAgent` — .NET Framework 4.8, x86. Каналы: `syntec`, `fake`, `folder`, `ftp`.
- `agent/build-usb.ps1 -SimulatorZip …\CNC520.zip` — пересобрать флешку (нужен архив симулятора 10.118, в репозитории его нет).
- `agent/e2e-fake.ps1` — сквозной прогон на эмуляторе стойки, без станка.
- Разбор G-кода: `convex/lib/parseGcode.ts`.
