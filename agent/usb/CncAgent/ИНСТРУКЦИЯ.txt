АГЕНТ ФРЕЗЕРНОГО СТАНКА (стойка Syntec)
=======================================

Что это
-------
Агент ставится НЕ на стойку ЧПУ (там Windows CE, на неё ничего не ставим), а на обычный
компьютер с Windows 7/10/11 рядом со станком («шлюз»). Шлюзом может быть и сам сервер очереди.
Агент по кабелю забирает с сервера задания, кладёт программу в память стойки, выбирает её
основной и сообщает серверу состояние станка. Кнопку «Старт» на стойке нажимает только оператор.

Сеть станков — отдельная, без интернета: адреса задаются вручную, без шлюза и DNS, чтобы ни стойка,
ни шлюз никуда не выходили и ничего не обновляли.

  сервер очереди        192.168.50.1
  шлюзы (агенты)        192.168.50.2 ... .19
  стойки ЧПУ            192.168.50.20 и дальше

Что на флешке
-------------
  Установить.cmd         установка или обновление агента (спросит адреса, ключ и имя станка)
  Проверить-стойку.cmd   однократная проверка связи со стойкой: режим, программа, тревоги, память
  Проверить-передачу.cmd передать на стойку ERP-TEST.CNC (только комментарий и M30, без движений)
                         или перетащенный на кнопку файл; покажет, каким путём файл лёг в память
  Настроить-сеть.cmd     только задать адрес этому компьютеру
  Удалить.cmd            удалить агента (программы в стойке не трогает)
  agent\                 сам агент и библиотеки Syntec Remote API
  redist\                Microsoft Visual C++ 2005 SP1 (x86), ставится автоматически при необходимости;
                         сюда же можно положить ndp48-x86-x64-allos-enu.exe, если на шлюзе нет .NET 4.8

1. На стойке (один раз)
-----------------------
  а) Соединить стойку кабелем с коммутатором сети станков (разъём Ethernet на стойке).
  б) Задать стойке адрес в сети станков, например 192.168.50.20, маска 255.255.255.0,
     шлюз — пусто или 0.0.0.0. Записать адрес.
  в) Включить сервер удалённого доступа: «Обслуживание → Сеть → Core server»
     (в разных версиях ПО пункт может называться Remote / Core Server). Включить запуск при
     включении стойки и запустить сервер. После этого стойка слушает порты 5566–5572.
  г) Проверить, что счётчик деталей стойки считает по M30 (параметры счётчика деталей,
     Part Count). Агент засчитывает деталь по росту этого счётчика; если он не растёт, деталь
     засчитывается, когда программа дошла до конца.

2. На шлюзе
-----------
  а) Подключить кабель сети станков.
  б) Запустить Установить.cmd, согласиться на права администратора.
     Установщик:
       - проверит .NET 4.8 и при необходимости поставит Visual C++ 2005 (x86);
       - задаст компьютеру адрес в сети станков, если его ещё нет;
       - спросит адрес стойки, проверит ping и порт 5566;
       - спросит ключ агента и имя станка (латиницей, например velber-1);
       - покажет, что видно на стойке, и запустит агента в фоне.
     Агент запускается сам при включении компьютера, вход в Windows не нужен.

3. Проверка
-----------
  - В веб-интерфейсе на странице «Станки» появился станок, «связь есть», видны режим,
    состояние и основная программа.
  - Запустить Проверить-передачу.cmd. Если ответ «ПЕРЕДАН через Remote API» и программа есть
    в списке — всё готово. Если «стойка не приняла файл» — включить общую папку стойки
    (см. «Запасная доставка» ниже) и повторить.
  - Поставить в очередь короткую программу на 1 деталь. Через несколько секунд она появится
    в памяти стойки и станет основной, задача перейдёт в «загружена».
  - Оператор нажимает «Старт» — задача «в работе»; после M30 — «выполнена».

Если не работает
----------------
  Журнал агента:  C:\Program Files (x86)\CncAgent\cnc-agent.log
  Настройки:      C:\Program Files (x86)\CncAgent\cnc-agent.json (после правки — перезагрузить
                  компьютер или в Планировщике заданий перезапустить задачу CncAgent)

  «нет связи с Remote API: стойка ... не отвечает»
      не включён Core server на стойке, неверный адрес стойки или кабель. Проверить-стойку.cmd.
  «не загружается библиотека Syntec (нужен Microsoft Visual C++ 2005 SP1 x86)»
      запустить redist\vcredist2005_x86.exe.
  «стойка не приняла файл (код SocketError (-16))»
      работает старая библиотека v4, а она не передаёт файлы на ПО 10.118. В папке агента должна
      быть папка syntec-10.118, в cnc-agent.json — "SyntecLib": "auto". Какая библиотека
      загружена, видно в Проверить-стойку.cmd («библиотека syntec-10.118 ...»).
  «стойка не приняла файл (код ...)»
      программа с таким именем сейчас выполняется, мало памяти на стойке или стойка запретила
      запись. Освободить память, повторить задачу в вебе («Повторить»). Если ошибка на любом
      файле — включить запасную доставку (ниже).

Запасная доставка через общую папку стойки
------------------------------------------
Состояние станка по-прежнему читается через Remote API, а файл, который Remote API не смог
установить, агент кладёт прямо в папку программ стойки (дальше — сразу туда).
  а) На стойке: «Обслуживание → Сеть», раздел «Resource Shared / Shared Folder Path»: открыть
     в сеть папку программ NcFiles (по сети или FTP). Записать путь, логин и пароль.
  б) В cnc-agent.json оставить "Link": "syntec" и добавить
       "RemoteDir": "\\192.168.50.20\NcFiles"            (общая папка)
     или
       "RemoteDir": "ftp://192.168.50.20/NcFiles", "FtpUser": "...", "FtpPassword": "..."
  в) Перезапустить задачу CncAgent и снова Проверить-передачу.cmd: в ответе должно быть
     «через папка ...» и «В списке программ стойки: есть».
  Если общая папка не открывается с шлюза (стойка на Windows CE отдаёт её по старому протоколу
  SMB1), включить на шлюзе «Компоненты Windows → Поддержка общего доступа к файлам SMB 1.0 →
  Клиент SMB 1.0» или использовать FTP. Сеть станков без интернета, поэтому это допустимо.
  «сервер недоступен»
      проверить кабель и адрес сервера; задания и события агент сохранит и отправит сам.

Запасной вариант без Remote API
-------------------------------
Если Core server на стойке так и не заработает, агент может только класть файлы в сетевую папку
или на FTP стойки (без состояния станка): в cnc-agent.json поставить "Link": "folder" и
"RemoteDir": "\\192.168.50.20\NcFiles" (или "Link": "ftp", "RemoteDir": "ftp://192.168.50.20/NcFiles",
"FtpUser", "FtpPassword"). Тогда выбирать программу и отмечать готовые детали придётся в вебе вручную.
